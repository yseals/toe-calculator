# toe-calculator
アライメントの計算補助ツール

[https://yseals.github.io/toe-calculator](https://yseals.github.io/toe-calculator)


## 概要
車のアライメント調整時の計算補助を行うツールです。

- トーの角度（分）、ミリの変換

## 動作環境
- github pages上
- ローカル環境で直接ブラウザ表示

## 特徴
- タイヤサイズから、トーの角度（分）とミリの変換を行います。
- 直径、半径から、トーの角度（分）とミリの変換を行います。

## 背景
トーイン調整をする際、直感的にはミリ表記だが、<br>
ミリ単位だと測定地点（タイヤ端、測定機器の端）によって測定値が異なるため<br>
角度による表記と、ミリ表記の変換が必要になり<br>
スマホでも見れるようにWebで確認出来るものを作成しました。
